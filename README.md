# Telegram File Sharing Bot
A Python bot (aiogram + SQLite) with force-subscribe, referral credits,
daily limits, premium access and admin tools.

## Setup
pip install aiogram aiosqlite
Copy .env.example to .env, fill in your values, then run: python bot.py
